# New Note NP

Small local Obsidian plugin that adds a "New note" button to the left ribbon.

## Install locally

Copy this folder to your vault:

```text
YourVault/.obsidian/plugins/new-note-np/
```

The plugin folder must contain:

```text
manifest.json
main.js
```

Then open Obsidian, go to `Settings -> Community plugins`, reload plugins if needed, and enable `New Note NP`.
